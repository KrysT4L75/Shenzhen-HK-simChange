## 仍需设备验证

2.0.0 未在 Android 模拟器或真机运行。以下是安装后需要实测的项目，不能由浏览器测试或编译结果代替：

1. 从已安装的同签名 1.2.0 覆盖升级，确认原换卡偏好保留。
2. Android WebView 冷启动、系统返回键、软键盘与系统栏适配。
3. 通知授权与拒绝、实际作业／考试提醒送达、重启后调度。
4. 位置授权与拒绝、行程定位前台通知、通知栏停止、系统杀进程后的状态提示。
5. 罗湖、文锦渡、上水及大学站实地位置确认与电量消耗。
6. 原双卡守护与通勤定位同时运行时的设备表现。
7. Android 系统文件选择器中的 JSON 导出与恢复。

没有进行真实交通方式分类评估。实现中的速度提示只表达“可能乘车”，不能准确区分公交和出租车；GPS 也不能证明上水出入闸。没有接入实时车费、账户支付或八达通记录。

## 提醒行为

作业与考试时间统一按 UTC+8 处理。通知可设置在事项时间、提前 15 分钟、1 小时或 1 天。提醒使用非精确系统闹钟，需允许通知，受系统省电与调度影响；不保证精确到分钟。完成事项会取消其提醒。
